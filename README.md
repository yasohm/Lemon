<p align="center"><strong>Your personal desktop AI companion for Ubuntu.</strong></p>

LEMON is an early-stage project for a floating desktop assistant with expressive eyes. The plan is to bring together text and voice chat, local and cloud AI, and permission-based desktop tools that keep you in control.

Read the [technical design paper](github%20intro/LEMON%20A%20Personal%20Desktop%20AI%20Assistant%20for%20Ubuntu.md) for the project vision.
